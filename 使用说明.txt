一、启动方法（共3步）

  1. 打开命令行（CMD或PowerShell），进入本目录：
     cd /d e:\Chat GPT6\资料百事通
  2. 启动服务：
     python app.py
  3. 浏览器访问：
     本机访问    http://127.0.0.1:8300
     手机访问    http://本机IP:8300  （手机与电脑须同一局域网/WiFi）
     管理后台    http://127.0.0.1:8300/admin

  默认管理员：admin / admin123（正式使用前请登录后尽快改密码）

  测试验收脚本（可选）：python tests.py
  （使用独立临时数据库，不影响正式数据，跑完自动清理）

二、AI智能搜索配置（V1.5新增）

  未配置API Key时：自动使用降级模式（规则解析），功能完整可用。

  启用真实AI（豆包大模型）：
  1. 设置环境变量后启动：
     CMD:        set DOUBAO_API_KEY=你的APIKey && python app.py
     PowerShell: $env:DOUBAO_API_KEY="你的APIKey"; python app.py
  2. API Key 获取：火山引擎控制台 → 火山方舟 → API Key 管理
     （https://console.volcengine.com/ark）
  3. 模型默认 doubao-lite-4k，可在 ai_service.py 顶部修改

四、数据库说明（SQLite，表结构）

  users              用户表（含role角色字段，预留扩展：user/admin及更多）
  industries         行业分类（is_open控制开放状态，后台可配置）
  documents          资料主记录（含status状态机：
                     pending待审核→published已发布；
                     rejected已驳回(带原因)；offline已下架）
  document_images    资料图片（一对多，支持排序，ref_type区分主资料/版本图片）
  audit_logs         操作与审核日志（上传/修改/删除/审核/下架全留痕）
  categories         层级分类表（行业→机构/业务/资料类型）
  document_versions  资料版本表（多版本管理，历史追溯）
  feedback           用户反馈表（有帮助/内容有误/已过时）
  discussions        社区讨论表（V2.0：parent_id回复/hidden隐藏）
  points_log         贡献积分流水表（V2.0起加分，V3.0起支持消费扣减）
  membership         会员表（V3.0：有效期/积分兑换或管理员开通）
  ad_rewards         广告激励记录表（V3.0：每日上限防刷）
  consultations      付费咨询表（V3.0：pending/answered/refunded）
  bounties           需求悬赏表（V3.0：open/fulfilled/closed）
  bounty_entries     悬赏应征表（V3.0：pending/accepted/rejected）

  后续预留扩展（架构已考虑）：真实支付订单、微信小程序端

五、已实现功能清单（均为真实功能，非静态展示）

  [首页] 大搜索框、AI智能搜索框(V1.5)、热门搜索词、行业分类
         （保险理赔开放，其余"暂未开放"）、三步引导、最新上传、
         常用资料类型、真实统计数据（不造假）
  [AI搜索] 自然语言描述需求 → AI解析条件（地区/机构/业务/资料类型）
         → 匹配资料 → 生成回答（含资料列表/来源/时间）
         无结果如实提示不伪造；信息不足时反问澄清；
         无API Key自动降级规则解析，功能不中断
  [搜索] 关键词（名称/标签/业务/机构/类型模糊匹配）+ 行业 + 省份 + 城市 +
         资料类型组合筛选，分页，空结果如实提示
  [详情] 全字段展示、多图切换、点击灯箱放大、作者信息、浏览计数
         版本历史入口、用户反馈按钮（有帮助/内容有误/已过时）
  [上传] 五步向导（分类→图片→脱敏→说明→预览提交）、多图上传、
         预览/删除/排序、Canvas手动脱敏（拖动涂黑、不可逆）、
         隐私确认勾选强制、行业级联选择（选择行业后加载机构/业务/资料类型）
  [版本管理] 已发布资料可提交新版本、版本历史查看、版本详情、
         待审核版本权限控制（仅作者和管理员可见）
  [纠错反馈] 详情页提交反馈、重复提交拦截、必填理由校验、
         后台反馈管理（处理/忽略）
  [社区讨论] 每条资料下的讨论区（V2.0）：发表/回复/删除、
         等级徽章+作者标识展示、管理员隐藏违规讨论、
         当日剩余额度实时显示
  [贡献等级] 积分规则（上传过审+10/新版本+5/反馈采纳+2/讨论+1）、
         五级等级（Lv1新手→Lv5社区之星）、作者主页等级徽章、
         积分流水全程留痕
  [发言额度] 按等级限制每日发言（Lv1:5条→Lv5:100条，管理员不限）、
         服务端强制校验防灌水、超限引导提升等级
  [AI社区整理] /api/ai/community_digest 汇总近期讨论高频问题、
         AI模式大模型提炼/降级模式关键词统计
  [VIP会员] 会员中心/vip（V3.0）：积分兑换开通（月度200分/年度2000分）、
         未过期顺延、开通记录；权益：搜索高级排序（浏览量/更新时间）、
         详情页打包下载全部图片ZIP、上传资料后台优先审核（置顶+标识）、
         全站昵称VIP徽标；管理端可为任意用户手动开通
  [广告激励] /ad（V3.0）：模拟广告位观看3秒后领取+5积分，
         每日上限3次（服务端强制防刷），积分攻略面板
  [付费咨询] 详情页"付费咨询作者"（V3.0）：10积分/次，作者在我的贡献
         "向我咨询"中回答后积分结算给作者；未回答可由提问者关闭退款；
         不能咨询自己的资料，权限全部服务端校验
  [需求悬赏] 悬赏大厅/bounty（V3.0）：发布悬赏冻结积分（最低10分）、
         他人以本人已发布资料应征、发布者采纳后积分结算给应征者、
         关闭则全额退回；进行中/已结束列表公开展示
  [作者主页] 公开作者信息、发布资料列表、贡献统计（资料数/浏览数/有帮助数）
  [个人中心] 我的上传记录、状态跟踪（待审核/已发布/已驳回+原因/已下架）、
         修改待审核与被驳回资料（可换图删图）、删除自己未发布资料
  [管理后台] 资料审核（通过/驳回/下架/重上架）、分类管理（层级维护）、
         反馈管理（处理/忽略）、用户管理（禁用/启用/角色调整）、操作日志
  [安全] 密码PBKDF2哈希、权限全部服务端校验、图片EXIF清除、
         未审核资料他人不可见、上传格式/大小/数量校验、路径防穿越
  [接口预留] /api/search /api/doc/<id> /api/categories /api/categories/tree
         /api/stats /api/ai/search /api/ai/community_digest
         /api/vip/status /api/bounties /api/consultations
         （均可用，供小程序端与第三方调用）

七、当前限制（如实说明）

  1. 商业化以积分模拟支付结算，真实支付（微信支付/支付宝）待接入：
     需注册微信/支付宝商户号 → 开通 Native/JSAPI 支付 →
     服务端下单回调验签 → 替换积分结算逻辑（预留订单表扩展位）
  2. 广告为模拟广告位，真实广告平台（如穿山甲）待接入：
     注册开发者 → 创建激励视频广告位 → 替换 /ad 页面为SDK调用 →
     服务端回调验证后再发积分
  3. 微信小程序端：后续阶段开发（API已预留）
  4. 当前为Flask开发服务器，适合演示与内网使用；
     正式公网运营需：更换生产服务器(waitress/gunicorn)、
     域名备案、HTTPS、隐私政策与用户协议上线
  5. 页脚"程序大小/最后保存时间"为启动时统计，改代码后重启即刷新
  6. AI搜索/社区整理未配置API Key时使用降级模式，精度低于真实大模型
